    管理頁持續無回應時怎麼處理？
    1. 確認 Mac 已開機並登入。程式更新切換時會短暫中斷，先等約 30 秒。
    2. 從原本安裝藥局程式的資料夾開啟 03-Manage.command。若仍無回應，執行 05-Enable-Autostart.command。
    3. 如果有手動執行 02-Start 的視窗，先在該視窗按 Control+C，再設定登入自動啟動。不要重複啟動兩個服務。
    4. 若出現 Bootstrap failed 或其他錯誤，保留訊息供檢查。不要重跑 01-Setup 或刪除資料庫。

    這項檢查只讀取狀態，不會代你修改 Mac 登入設定。服務已停止時，網頁不能自行啟動它。

    iPhone 連線與 Norton 設定

    先確認 iPhone 與 Mac 可互通，並從手機原有的藥局 App 按「檢查連線」。只在 Mac 開得了管理頁，仍不能確認手機已連通。

    Norton 開啟後連線失敗

    在 Norton 開啟 Security → Smart Firewall → Settings → Traffic Rules → Application rules，找到 supervisor.mjs，確認設為綠色勾選「允許」。Norton 可能以這個名稱顯示藥局服務，不一定叫 node。

    保留防火牆開啟，再用 iPhone 檢查連線並同步。若清單中名稱或位置不同，先核對程式來源；不要把其他不相關程式全部放行。

    App 無法直接讀取 Norton 的規則，因此連線失敗時不會自動判定一定是防火牆或憑證。

    Mac 的加密副本

    此服務沒有資料庫密碼，無法檢視客戶內容。撤銷裝置只會停止未來同步；已存在遺失裝置上的資料不能遠端收回。同步快照與升級前檢查點不是外接離線備份。
